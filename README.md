# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 校园放映 · 主题编单

在「主题编单」页签中，可以从现有章节挑选片段，插入讨论停顿与人物访谈，编成一份不修改原片的放映清单。

设计要点（对应需求）：

- **只引用、不改原片**：编单条目只保存章节 id、源片入点/出点与讲述者 id，不复制或裁剪素材；同一章节可被多次引用并取不同镜头区间。
- **连续放映时间**：片段按顺序拼接，讨论/访谈停顿不占时长；条目的放映起止时间完全由前面的条目推导，因此调整前段长度后，后续停顿与字幕的放映时间整体跟随移动。
- **临时支线可返回**：放映中在停顿点或片段内点开热点、人物访谈属于临时探索，支线结束后回到**编单对应位置**并恢复播放状态。
- **两套时间不混淆**：探索手记收藏的始终是**原片位置**（章节 id + 源片时间），与编单连续时间分开存储、分开显示；手记的「回到现场」会先退出编单再回到原片。
- **草稿与提交边界**：编辑在草稿中进行，可随时放弃；含错误级无效片段时禁止提交。提交时若正在放映，会捕获当前镜头并在新时间轴上恢复，避免正在播放的片段突然换内容。
- **无效片段可修正**：零时长、越界、引用的章节/人物缺失都会标红并给出原因，片段越界支持一键修正到章节边界；缺失引用的条目会保留以便重新指定素材。
- **可移植的导出/导入**：导出为 `.shoreline-program.json`，附素材清单（manifest）。在另一台设备打开时按文件恢复相同顺序；缺失素材被可预见地标红保留，无法识别的条目被剔除，其余顺序不变。

## 验证脚本

无需额外依赖，使用项目自带工具链：

- `node scripts/verify-program.mjs`：时间轴推导、无效片段、级联移动、导入导出与缺失素材处理等纯逻辑测试。
- `node scripts/verify-components.mjs`：用 Vite SSR 构建验证编单组件渲染，以及草稿提交边界、支线返回、自动推进等引擎行为。
